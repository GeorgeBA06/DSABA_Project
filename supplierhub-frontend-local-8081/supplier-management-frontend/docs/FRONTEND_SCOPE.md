# Границы frontend

Компактный корпоративный UI на русском языке для 97 операций, доступных в Stage 4. Выполненные сценарии и ограничения описаны в `INTEGRATION_REPORT.md`.

Нет глобального поиска, клиентского конструктора методики рейтинга, фиктивных данных, отправки юридических документов почтой, микросервисного взаимодействия и операций без backend API. Разделы с множеством близких сущностей реализованы через вкладки одного реестра. Решения/формулы в React не дублируются — авторитетен backend.

Два добавленных к backend `OrderVersionLineView` поля (`productId`, `lineNo`) являются единственным контрактным дополнением, необходимым для корректного повторного редактирования заказа.
